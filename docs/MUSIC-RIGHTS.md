# Soundtrack distribution status

The private reference repository contains the original “Moonlit Witch’s Garden” MP3 and a cover image. Its local documentation identifies the track as supplied for a prior release and attributes it to Shamelesabyss. The available source files do not establish the composition/recording chain, written public-redistribution grant, music-generation tool/model/terms, or provenance and redistribution rights for the cover art.

Prior inclusion in a private or test APK is not proof that the audio and cover may be republished in this new public source repository or its APK. To honor the project directive, this public repository does **not** contain either file. The untouched private repository remains the reference copy.

The Android project already includes an offline Media3 player, local playlist manifest, transport controls, volume, shuffle and repeat support. The manifest is intentionally empty, and the player explains why playback is unavailable. No replacement music has been generated or substituted. Add the original files only after the owner can verify and document the rights and applicable generation-tool distribution terms for both the recording and cover.
