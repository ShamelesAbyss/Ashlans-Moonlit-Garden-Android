# Native soundscape

The small garden/rain loops and interaction chimes in this folder are reproducible, procedurally synthesized PCM WAV files generated by `scripts/create_sounds.py`. They contain no third-party samples, recordings, remote assets, or model-generated tracks. They are environmental ambience and brief UI/gameplay effects, kept separate from the original music playlist.

Regenerate with:

```sh
python3 scripts/create_sounds.py
```

The original MP3 soundtrack and its cover image are deliberately not present here while their public redistribution rights remain unresolved; see `docs/MUSIC-RIGHTS.md`.
