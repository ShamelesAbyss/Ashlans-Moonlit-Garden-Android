# Changelog

## 1.0.0 — Moonlit Rebirth (native development build)

- Began a fresh Kotlin/Jetpack Compose/Canvas Android application with a distinct app ID; no private Git history or WebView bundle is carried over.
- Reimplemented the garden, nine-bed crop loop, three crops, woodland forage, six fictional cabinet recipes, Nettle interactions, Bramble’s economy and upgrades, memorial offerings, journal, settings, and v1 JSON save/import/export migration logic.
- Added private DataStore persistence, a recoverable pre-import copy, and journal-preserving import/restore behavior.
- Reused the project’s official launcher identity, adaptive icon variants, monochrome icon, splash art, and original pixel jukebox sprite.
- Added an offline Media3 player foundation, local playlist manifest, and transport/shuffle/repeat/volume controls. The playlist remains empty pending documented redistribution rights for the supplied MP3 and cover.
- Added JVM game-rule/migration tests and GitHub Actions for debug build verification and tagged development releases.

This entry describes implementation scope; it does not claim unperformed tests, phone installation, audible playback, or production signing. See the current GitHub Actions result and `BUILD.md` for verified status.
